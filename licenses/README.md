# Sovereign Source license discussion

The [Sovereign Source Super Intellectual Property License, version 0.1](SS-SIP-0.1.md) is a published draft exploring permissions and attribution for covered material.

It is a custom license draft, not a claim of Open Source Initiative approval. Its presence in this repository does not, by itself, apply it to a particular work; application requires an explicit notice from an authorized rights holder.

The license text distinguishes permissions for covered material from separate commercial agreements. Attribution does not, by itself, establish ownership or a right to payment. This overview does not change the published license text or any existing grant.

Read the [project principles](../docs/PUBLIC_OVERVIEW.md) for the broader public discussion of permission, attribution and contributor rewards.
