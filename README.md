# Sovereign Source AI

**AI that respects where knowledge comes from and shares value with the people behind it.**

Sovereign Source is a research initiative exploring permission, attribution and contributor rewards. We believe more capable AI should expand human opportunity and support the continued creation of useful knowledge.

The idea of **Super Intellectual Property** broadens recognition to works, ideas, contributions and influences. It is a project concept, not a new category of statutory ownership. Recognition, permission and compensation are distinct questions, and participation should be voluntary.

This repository contains public principles and opinion articles. The project does not currently offer a production model or an operating contributor-payment service.

Visit [sovsrc.si](https://sovsrc.si) or browse the [public library](docs/index.html).
